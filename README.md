# IFES Revit Maintenance Toolkit

Dynamo custom package for maintenance management in Brazilian Federal Higher Education Institutions (IFES).

## Description

Custom Dynamo package for managing maintenance information requirements in BIM models, supporting structured information management and IFC-based interoperability throughout the building lifecycle.

## Features

- Management of maintenance information requirements;
- Standardized insertion of maintenance parameters into BIM models;
- Organization of maintenance information into custom Property Sets;
- Mapping of maintenance attributes to IFC entities;
- Automated parameter management using Dynamo and Python;
- Export of structured maintenance information to IFC.
